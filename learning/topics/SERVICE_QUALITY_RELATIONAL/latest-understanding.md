# 今の理解（骨格）

10/6〜14 の記録（[records/](records/)）から転記。**本人確認前（draft）**。定義・具体・結論だけに絞る。経過は日付フォルダと records/ に残す。

## 設定
- 買い手が代金 p を提示 → 売り手が受諾/拒否 → 先払い → 売り手が品質（高/低）を選ぶ → 成果（良/悪）が両者に観察される。
- 高品質なら必ず良い成果。低品質なら確率 q で良い成果、1−q で悪い成果（0<q<1）。悪い成果が出たときだけ低品質が発覚する。
- 利得：買い手 = 成果の価値 − p。売り手 = 高品質 p − c、低品質 p。外部機会は売り手 U_0、買い手 0。割引因子 δ（0<δ<1）。
- 成果連動の代金は結べない。結べるのは固定額 p と、取引を続けるか打ち切るかだけ。

## 設問0の二条件
1. 高品質は社会的に望ましい：WTP_g − c > U_0
2. 低品質だけなら買い手は取引したくない：U_0 > q·WTP_g + (1−q)·WTP_b

## 一回限り
- 売り手は p がどんな値でも低品質を選ぶ（p > p − c）。買い手はそれを予想し p < U_0 を出して取引が起きない。
- 失われる価値は WTP_g − c − U_0 > 0。主因は売り手の低品質選択（モラルハザード）で、代金を上げても直らない。

## 長期（悪い成果が出たら取引停止、の戦略）
- 継続価値：V_H = (p − c)/(1 − δ)、V_L = U_0/(1 − δ)。
- 売り手の誘因条件：c ≤ δ(1−q)(V_H − V_L)、すなわち p ≥ U_0 + c(1 − δq)/(δ(1 − q))。
- 両立条件：WTP_g ≥ U_0 + c(1 − δq)/(δ(1 − q))。成り立たなければ、買い手が参加しないか、売り手がモラルハザードを犯す。
