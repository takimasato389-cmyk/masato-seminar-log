# 解くべき数学的問題の定式化（作業用資料）

## BLOCK 0：与えられているもの（課題文に書いてあることだけ）

**登場人物**
1. この世にはBuyer とSellerという二人しか存在していない。

**一期の手番**
2. まず、Buyerが代金を提示する。
3. Sellerはその代金によって取引に応じるか、断って外部の機会を使うかを決める。
4. Sellerが拒否した場合、取引は行われず、Sellerは外部機会を利用できる。
5. 応じた場合、Buyerは代金を先払いし、Sellerは高品質か低品質の商品を出すかを選ぶ。

**費用**
6. 高品質の提供には費用がかかるが、低品質の提供には費用がかからない。

**成果の出方**
7. もし高品質を出した場合、100％の確率で良い成果を得る。ただ、低品質の場合、一定の確率で良い成果を得、その他の場合は悪い成果を得る。

**誰が何を見られるか**
8. 5の際、BuyerはSellerがどちらを選んだか観測できない。
9. 実現した成果は両者に観察される。

**使える契約**
10. 代金を実現した成果に連動させる契約は利用できない。

**長期の場合**
11. 長期的関係では、同じ買い手と売り手が繰り返し取引する。
12. あらかじめ決められた最終期は存在しない。

（それ以外はこの世に存在しない）
