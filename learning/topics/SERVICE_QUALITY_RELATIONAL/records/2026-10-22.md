## 2. 現在の理解（骨格）

### 設定（設問0）
- **プレイヤー**：買い手と売り手の2人。
- **一期の順序**：買い手が代金 p を提示 → 売り手が受諾か拒否 → 受諾なら買い手が先払い → 売り手が品質（高／低）を選ぶ → 成果（良い／悪い）が実現し両者に観察される。拒否なら取引なし、売り手は外部機会。
- **確率**：高品質なら必ず良い成果。低品質なら確率 q で良い成果、1−q で悪い成果（0<q<1）。
- **利得**：買い手は成果の価値（WTP_g または WTP_b）− p。売り手は高品質 p − c、低品質 p。外部機会は売り手 U_0、買い手 0（正規化）。
- **長期**：割引因子 δ（0<δ<1）で将来を割り引く。無限期。

| 記号 | 意味 | 範囲・出所 |
| --- | --- | --- |
| p | 買い手が提示する代金 | 0以上（本人の仮定） |
| q | 低品質のとき良い成果が出る確率 | 0<q<1（課題文「必ず」とは言っていない） |
| WTP_g, WTP_b | 良い成果／悪い成果の買い手にとっての価値 | 本人が導入 |
| c | 高品質の費用 | c>0（課題文） |
| U_0 | 売り手の外部機会の利得 | U_0>0（本人の仮定） |
| δ | 割引因子 | 0<δ<1（本人。理由は下） |

**本人が置いた仮定**：期待値で評価する（リスク中立）／売り手の利得は成果に直接依存しない／両者は過去の代金と成果をすべて覚えている／売り手は無差別のとき受諾する（p=U_0 でも受諾）／買い手の取引不成立時の利得を0にする（正規化。理由は未記述）。

**δ の範囲の理由（本人）**：δ=1 だと「毎年1万円を永遠」と「毎年2万円を永遠」がどちらも無限になり比べられない。δ=0 だと将来の取引を失う恐れを感じないので、一回限りと同じになる。

### 設問0の二条件（本人が導出）
1. 高品質は社会的に望ましい：**WTP_g − c > U_0**
2. 低品質だけなら買い手は取引したくない：**U_0 > q·WTP_g + (1−q)·WTP_b**

つなげると WTP_g − c > U_0 > q·WTP_g + (1−q)·WTP_b。本人の解釈は「社会的な望ましさは 高品質取引 ＞ 外部取引 ＞ 低品質取引」。

### 設問1：一回限りの関係
- 売り手は受諾後、p − c < p なので **低品質**を選ぶ。**p がどんな値でも**そうなる。
- 買い手はそれを予想し、売り手が拒否する **p < U_0** を提示する。取引は起きない。
- 利得は買い手 0、売り手 U_0。失われる価値は **WTP_g − c − U_0 > 0**。条件(1)により、高品質取引は社会的に望ましいのに実現しない。
- 主因は買い手が払わないことではなく、売り手が利得計算により低品質を選ぶこと（モラルハザード）。代金を上げても解決しない。

### 設問2：長期的な関係
- **買い手の戦略（本人）**：最初は売り手がぎりぎり受諾する p を提示。良い成果なら次の期も同じ p。悪い成果なら以後、売り手が拒否する p（U_0 より小さい）を提示し続ける。
- **売り手の戦略**：受諾して高品質を選ぶ。悪い成果が出た後は、取引が起きない。
- **継続利得**：V_H = (p − c)/(1 − δ)（立式は本人、解いたのはAI代行）。V_L = U_0/(1 − δ)（罰の後は取引なしで毎期 U_0。本人が訂正して到達）。
- **今期だけ低品質にずらす価値（本人）**：p + δ·( q·V_H + (1 − q)·V_L )。
- **売り手の誘因条件**：c ≤ δ(1−q)(V_H − V_L)。代入すると **p ≥ U_0 + c(1 − δq)/(δ(1 − q))**（立式は本人、整理はAI代行、乱数10万組で同値性を検算）。
  - 本人の文章化：「売り手は、高品質を作る費用と、割引 × バレる確率 × バレたときに失うものを比べて高品質を選ぶ。」
  - 買い手の道具は提示する値段だけで、値段でモラルハザードを抑える（本人）。
- **買い手の参加条件（本人）**：WTP_g ≥ p。
- **両立条件（本人、p を消して到達）**：**WTP_g ≥ U_0 + c(1 − δq)/(δ(1 − q))**。成り立たなければ、買い手が参加しないか、売り手がモラルハザードを犯す。
